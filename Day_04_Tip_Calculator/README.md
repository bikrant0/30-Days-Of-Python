# Day 3: Tip Calculator

A console-based Tip Calculator using pure Python. This project features error handling, clean loop structure and great user experience.

## How to Run

1. Ensure Python is installed on your machine.
2. Run the script from your terminal:
   `python tip_calculator.py`
