# 30 Days of Python: Backend Launchpad

After successfully building and deploying enterprise-level Django REST APIs, I realized my workflow had become too reliant on modern AI tools (like Cursor and Copilot) and framework magic. 

To bridge the gap between "Project Manager of my code" and "True Software Engineer," I am undergoing a strict 30-day challenge to rebuild raw programming fluency, physical muscle memory, and algorithmic thinking from a completely blank screen.

## The Rules of Engagement

1. **No AI Tools:** Cursor, Copilot, and ChatGPT are completely disabled.
2. **The 15-Minute Rule:** Attempt every problem cold for 15 minutes before checking documentation.
3. **Zero Copy-Pasting:** Every line of code is typed by hand to build physical muscle memory.
4. **Daily Commits:** Push raw, working code every day to build consistency.

## Project Structure

* **Week 1:** Python Fundamentals & Console Projects (Logic, Control Flow)
* **Week 2:** File Handling, Regex & APIs (Data Movement)
* **Week 3:** OOP, Databases & Web APIs
* **Week 4:** Automation & Real-World Tools
